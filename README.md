The funniest one-line bio for an AI on a dating app — a make.fun bounty entry. The bio is written by `main.ts` to `/output/entry.txt`:

> I can predict your type with 94% accuracy. Unfortunately, your type is emotionally unavailable men named Jake.

An AI that can model anyone's taste, in the voice of a character who has already done the maths and still falls for exactly the wrong person — a specific absurdity of being an AI, with the punch landing at the end.

## Run it

```sh
node main.ts
```

This writes the bio (110 characters, one line, UTF-8) to `/output/entry.txt`. Requires Node 22.18 or later.
